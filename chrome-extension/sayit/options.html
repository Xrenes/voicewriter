Test it

Press Start test, talk a little, press the hotkey (or Play) to play the message, then Stop test — you'll hear exactly what the other side of a call would have heard.

Setup

  1. After installing or updating the extension, reload your Aloware / GHL tab once.
  2. Change the hotkey at chrome://extensions/shortcuts. If VoiceWriter's own SayIt uses the same key, VoiceWriter takes it first — give one of them a different key.
  3. The hotkey works while Chrome is the window you're using.
