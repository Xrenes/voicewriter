Guide & API Keys

Dictation (hold-to-talk)

  1. Open console.groq.com/keys and sign up (free, no card required).
  2. Click "Create API Key", give it any name, and copy the key (starts with gsk_).
  3. In this Settings window, open API Keys & Usage above and paste it into Groq API key, then Save.
  4. Click a text field anywhere, hold Alt+C, speak, then release — the text is inserted automatically.

Without a key, dictation still works using the local model — just less accurate. See the Transcription Engine section to download it.

Speak selection aloud

  1. Uses its own separate Groq key (Groq gives each key its own free-tier limit). Get one the same way: console.groq.com/keys.
  2. Paste it into Speak-aloud API key in API Keys & Usage, then Save.
  3. Select any text on screen, press Control+Alt+C to hear it read aloud. Press again to stop.

Rewrite selected text (Alt+R / Alt+P / Alt+H)

  1. Uses your main Groq key (Dictation's key above) — no extra setup.
  2. Select text in any app, then press one of:
    • Alt+R — Refine: spelling, grammar and sentence structure are corrected and the wording is smoothed, keeping your meaning and tone.
    • Alt+P — Professional: a casual draft becomes a polished, courteous reply for clients and colleagues on WhatsApp, LinkedIn or email.
    • Alt+H — Humanize: stiff or AI-sounding text is rewritten so it reads naturally, like a person wrote it.
  3. The result replaces your selection automatically. Names, numbers, prices, dates and links are kept as written.
  4. A small note appears near the mouse while it works ("Refining…", "Making it professional…", "Humanizing…"). Keep the text selected and don't switch windows until it says it's done.

Wheel (Live / Record / SayIt / Web / AI)

  1. Press Shift+Alt+C to open the wheel.
  2. Live, Record and Web have their own guides below. While a recording runs, its wedge reads Stop.
  3. SayIt opens two choices: Play sends your saved message into the call (it reads Stop while playing), and Message opens the SayIt window to record or change it. Press Esc to go back.
  4. AI opens a chat window — needs its own Groq key, see below.
  5. Refine, Professional and Humanize stay on their hotkeys (Alt+R, Alt+P, Alt+H).

Live (a call, transcribed as you talk)

  1. Open the wheel (Shift+Alt+C) and click Live. It records like Record, and a see-through window shows the conversation as it's spoken: your words in white, the other side in yellow.
  2. Words appear about a second after they're said, dimmed while the person is still talking, and settle when they pause.
  3. Drag the window by its top bar, resize it from any edge, and use A−/A+ for the text size. Copy puts the whole conversation on the clipboard; ✕ hides the window while recording continues.
  4. Click Live again (it reads Stop) or the small floating button to stop. The conversation stays in the window, and you can save the recording as usual.
  5. Uses your Dictation Groq key. If Groq limits the key, the window says so and new lines may lag a few seconds; none are lost.

AI chat wedge

  1. Needs its own Groq key (can be the same key as Dictation, or a separate one/account): console.groq.com/keys.
  2. Paste it into AI (Groq) API key in API Keys & Usage, then Save.
  3. Pick a model from the dropdown that appears (each one is tested automatically; pick one marked ✓).
  4. Open the wheel (Shift+Alt+C) and click AI to start chatting. You can attach an image/screenshot to ask about it.

Record (calls and meetings, with a labeled transcript)

  1. Open the wheel (Shift+Alt+C) and click Record. Your mic and everything this PC plays (the other side of a call, a video, a meeting) are recorded as separate tracks.
  2. Click the small floating button (or Record again) to stop. Preview it, pick a name and folder, then Transcribe & Save.
  3. The audio is saved first; the transcript then appears with each line labeled You (your mic) or Device (what the PC played) and timestamped. It's also saved as a .txt next to the audio.
  4. Transcription uses your Dictation Groq key. If it fails (no key, no internet), the recording is kept and you can press Retry.

Web browser

  1. No API key required.
  2. Press Alt+W to open a small in-app browser (defaults to chatgpt.com) — press again to hide it, press once more to reopen where you left off.
  3. Change the default site by typing a new URL in its address bar; it's remembered next time.
  4. Email/password sign-in works and persists across restarts. "Continue with Google" will not work — Google blocks sign-in inside any embedded browser window as an anti-phishing measure, in every app that does this, not just VoiceWriter.

"Clean up with AI" (dictation polish)

  1. Uses your Dictation Groq key above — no separate key needed.
  2. Turn it on in the General section above. Falls back to local grammar rules when offline or without a key.
