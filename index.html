Guide & API Keys

Dictation (hold-to-talk)

  1. Open console.groq.com/keys and sign up (free, no card required).
  2. Click "Create API Key", give it any name, and copy the key (starts with gsk_).
  3. In this Settings window, open API Keys & Usage above and paste it into Groq API key, then Save.
  4. Click a text field anywhere, hold Alt+C, speak, then release — the text is inserted automatically.

Dictation needs this key — it runs on Groq.

Speak selection aloud

  1. Open the Voice Models section above and download the Kokoro voice (one-time, ~190 MB, no API key, no account).
  2. Select any text on screen, press Control+Alt+C to hear it read aloud. Press again to stop.

English/Latin-script only. Runs fully offline — no cost, no usage limit.

Refine wheel (Refine / Bangla / Translate / Record / Web / AI)

  1. Select some text, then press Shift+Alt+C to open the wheel.
  2. Refine and Bangla rewrite the selection using your main Groq key (Dictation's key above) — no extra setup.
  3. Translate picks a target language, then re-types the translation. Only an English translation is also spoken aloud (via Kokoro); Bangla/Spanish/Italian stay text-only.
  4. Record and Web need no API key at all (see their own guides below).
  5. AI opens a chat window — needs its own Groq key, see below.

AI chat wedge

  1. Needs its own Groq key (can be the same key as Dictation, or a separate one/account): console.groq.com/keys.
  2. Paste it into AI (Groq) API key in API Keys & Usage, then Save.
  3. Pick a model from the dropdown that appears (each one is tested automatically; pick one marked ✓).
  4. Open the wheel (Shift+Alt+C) and click AI to start chatting. You can attach an image/screenshot to ask about it.

Record (voice memo with transcript)

  1. No API key required for recording itself.
  2. Open the wheel (Shift+Alt+C) and click Record, or use it from the wheel directly.
  3. Speak, then stop — a transcript window opens, transcribed with your Dictation Groq key.

Web browser

  1. No API key required.
  2. Press Alt+W to open a small in-app browser (defaults to chatgpt.com) — press again to hide it, press once more to reopen where you left off.
  3. Change the default site by typing a new URL in its address bar; it's remembered next time.
  4. Email/password sign-in works and persists across restarts. "Continue with Google" will not work — Google blocks sign-in inside any embedded browser window as an anti-phishing measure, in every app that does this, not just VoiceWriter.

"Clean up with AI" (dictation polish)

  1. Uses your Dictation Groq key above — no separate key needed.
  2. Turn it on in the General section above. Falls back to local grammar rules when offline or without a key.
