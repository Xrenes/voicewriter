How it works

Four steps, then you forget it's there.

  1. 01

    Install and forget it

    VoiceWriter starts with your PC and sits in the tray. There is no window on screen unless you open one.

  2. 02

    Click into a field

    An email, a chat box, a code editor, a form — anywhere you would normally type.

  3. 03

    Hold Alt+C and speak

    Hold the keys, say what you want written, and release them when you're done. The hotkey is rebindable.

  4. 04

    Your sentence is typed in

    Punctuation and spelling included, right where your cursor was. It pastes as one block, so nothing is dropped.

What's inside

Built to stay out of your way.

Accurate by default

Uses Groq's Whisper Large v3 for state-of-the-art accuracy on names, numbers, and punctuation. Falls back to a local model automatically when you're offline or without a key.

Runs offline too

Download a local whisper.cpp model once and dictation works with no network at all. Your audio never leaves the machine.

Keys, not clicks

Hold to talk, release to insert. No "start recording" button, no toggle to forget. Just one motion.

No window in the way

Nothing on screen unless you open the settings panel from the tray. Click anywhere else and it tucks itself away.

Light on the machine

About 25 MB of memory sitting idle. It starts with Windows and waits for the hotkey — nothing more.

Your key stays yours

The Groq API key is held in the Windows Credential Manager, not a plain-text file. Local mode needs no key at all.

Usage at a glance

The tray panel shows requests today, requests per minute, and an estimated share of the free-tier daily limit — green, then amber, then red.

Accuracy

Cloud when you want it, local when you need it.

Groq — best spelling

Paste a free key from console.groq.com. A few seconds of audio go to Groq's Whisper and come back as clean, punctuated text — sharp on proper nouns and figures.

Local — fully private

Pick a model size in the tray panel and download it once. Everything then runs on your CPU with no connection. Slower, but nothing leaves the PC.

Auto — no thinking

Leave it on Auto and VoiceWriter uses Groq when it can and the local model when it can't. You never have to switch modes by hand.

Before the first launch

Windows may show a blue “Windows protected your PC” screen because the app isn't signed yet. Click More info, then Run anyway. Signing is on the roadmap.

First-run setup

Open the tray (the ▲ near the clock), click the VoiceWriter icon, and either paste a free Groq API key or download a local model from the same panel.

Uninstall

Settings › Apps › VoiceWriter › Uninstall. It removes the app and its Start Menu shortcut.

Questions

Straight answers.

Does my voice get sent anywhere?

Only if you choose the Groq engine. In that mode a few seconds of audio per dictation are sent to Groq's API and the text comes back. In Local mode nothing leaves your machine — the model runs on your CPU. Auto mode uses Groq when it can reach it and the local model otherwise.

Do I need an API key?

No. Download a local model from the tray panel and VoiceWriter works fully offline with no account. A free Groq key just gives you higher accuracy and much faster results.

Where is my Groq key stored?

In the Windows Credential Manager, not a plain-text file. The settings panel only ever shows a masked version of it.

Why does Windows warn me when I run it?

The installer isn't code-signed yet, so SmartScreen flags it as coming from an unknown publisher. Choose More info › Run anyway. The installers come straight from the GitHub Releases page.

Where does the text go?

Into whatever text field had focus when you pressed the hotkey. VoiceWriter copies the transcript and pastes it as one block, so long sentences and unusual spellings come through intact.

Is there a Mac or Linux version?

Windows only for now. The app uses Windows audio, tray, and input APIs directly, so a port isn't a quick change.

How do I close it?

Open the tray icon and choose Quit, or end the process from Task Manager. Closing the settings window just hides it — the app keeps listening for the hotkey.
